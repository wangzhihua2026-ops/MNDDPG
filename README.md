# MNDDPG: Privacy-Aware Multi-Objective IIoT Task Offloading

This repository contains the public research code accompanying the MNDDPG paper. It provides the simulation environment, MNDDPG model components, privacy-aware route masking, continuous-action projection, federated aggregation utilities, experiment configurations, evaluation tools, and runnable examples.

## 1. Environment

Install the Python dependencies with:

```bash
pip install -r requirements.txt
```

or create the Conda environment:

```bash
conda env create -f environment.yml
conda activate mnddpg-exp
```

## 2. Data Preparation

No external dataset is required. Experimental samples are generated by the simulator from scenario seeds, task profiles, MMPP arrivals, privacy tiers, node heterogeneity, and link dynamics.

```bash
bash scripts/download_data.sh
bash scripts/preprocess_data.sh
```

## 3. Quick Validation

Run a short training job:

```bash
python train.py --config configs/proposed.yaml --rounds 1
```

Evaluate the generated checkpoint:

```bash
python evaluate.py --config configs/proposed.yaml \
  --checkpoint outputs/checkpoints/global_weights.npz \
  --mode seen --steps 24
```

Run the end-to-end validation workflow:

```bash
python reproduce.py --profile smoke
```

Generated checkpoints, logs, numerical results, tables, and figures are written under `outputs/` and are excluded from version control.

## 4. Experiment Configurations

The repository separates quick validation settings from longer experiment configurations:

```text
configs/proposed.yaml          quick training and evaluation
configs/paper_main.yaml        main experiment configuration
configs/paper_baselines.yaml   comparison configuration
configs/paper_ablation.yaml    ablation configuration
configs/paper_sensitivity.yaml sensitivity configuration
```

The longer workflow can be launched with:

```bash
python reproduce.py --profile paper
```

Configuration values may be overridden from the command line, for example:

```bash
python reproduce.py --profile paper --steps 100 --scenario-limit 10
```

Focused launchers are also available:

```bash
bash scripts/run_baselines.sh
bash scripts/run_ablation.sh
bash scripts/run_sensitivity.sh
```

## 5. Methods and Evaluation

The experiment interfaces cover MNDDPG and the comparison methods used by the evaluation workflow, including PM-Soft-MoE, MO-DDPG, MO-SAC, CAPQL, PGMORL, FL-MO-SAC, and FedMORL. All methods use the shared simulator, feasible-route mask, continuous-action projection, objective vector, and reporting interface.

The evaluation utilities report latency, energy, reliability, privacy-policy match, constraint violations, normalized hypervolume, communication cost, convergence behavior, and seen/unseen scenario performance. Statistical reporting includes per-seed records, confidence intervals, and paired comparisons.

## 6. Project Layout

```text
configs/         experiment settings
data/            simulator data notes and generated inputs
scripts/         workflow launchers
src/data/        simulator, schemas, and preprocessing
src/models/      MNDDPG components, comparison methods, replay, and losses
src/training/    training, federation, optimization, and checkpoints
src/evaluation/  metrics, evaluation protocols, and statistical tests
src/experiments/ experiment orchestration and artifact generation
outputs/         locally generated artifacts (not versioned)
tests/           automated tests
```

Run the automated test suite with:
