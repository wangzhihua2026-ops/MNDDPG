# Experiment Specification

## 1. Research Goal

This project supports the MNDDPG paper experiment workflow for privacy-aware task offloading in Industrial Internet of Things systems. The experiment goal is to evaluate whether MNDDPG improves the latency, energy, reliability, and privacy trade-off under federated multi-objective training.

## 2. Data and Simulator

No external dataset is used. Experimental samples are generated by the edge-offloading simulator from:

- task classes: compute-intensive, data-intensive, real-time-sensitive
- dynamic arrivals: MMPP-style low, normal, and burst states
- privacy tiers: low, medium, high ordinal privacy levels
- infrastructure: local device, six edge nodes, optional cloud route
- seen/unseen protocols: held-out seeds with matched or shifted generator priors

The `data/` directory records simulator inputs, seed files, and processed artifacts rather than downloaded datasets.

## 3. Proposed Method

MNDDPG contains:

- shared observation encoder
- four objective experts for latency, energy, reliability, and privacy
- context gating network for hard expert selection
- proxy-weight network for adaptive scalarization during training
- masked route logits and straight-through Gumbel-Softmax
- continuous action projection for bandwidth, CPU ratio, and transmit power
- prioritized replay and multi-objective critics
- federated clipped aggregation with secure-aggregation byte accounting

## 4. Baselines and Comparators

The manuscript names MNDDPG, PM-Soft-MoE, MO-DDPG, MO-SAC, CAPQL, PGMORL, FL-MO-SAC, FedMORL, plus supplementary RL, MORL, federated, privacy-aware, and engineering references.

This migration creates the MNDDPG implementation path and baseline scaffolds. Full baseline fidelity can be filled in incrementally while preserving the shared simulator, mask, projection, metric, and CSV interfaces.

## 5. Evaluation Metrics

Primary metrics:

- normalized hypervolume
- average latency
- average energy
- task reliability
- violation rate
- privacy-policy match
- high-sensitivity violation rate
- communication bytes
- convergence round
- expert entropy and selected-route distribution

Statistical reporting uses mean, standard deviation, confidence intervals, and paired bootstrap fields.

## 6. Main Experiment

The main experiment trains/evaluates MNDDPG under the shared route-resource interface with fixed split seed 3407 and independent run seeds. The smoke-test configuration runs a small number of rounds and steps while preserving the same code path.

## 7. Ablation Experiment

Ablation groups:

- Full MNDDPG
- w/o Proxy Weights
- w/o Context Gating
- Soft Routing
- w/o Privacy Mask
- w/o Federated Clipping
- w/o Proxy + w/o Gating
- w/o Proxy + Soft Routing
- w/o Gating + Soft Routing
- w/o Privacy Mask + w/o Clipping

## 8. Sensitivity Experiment

Sensitivity hooks cover privacy composition, load level, synchronization interval, clipping norm, Gumbel temperature, and hidden width.

